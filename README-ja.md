## 🎯 はじめに：この日本語Pythonは「むずかしい作業なし」で使えます

GitHub にはたくさんのファイルが入っていますが、  
**日本語で Python を書いて動かすために必要なのは、たった 2 つのファイルだけです。**

- `japanese_keyword.py`  
- `japanese_preprocessor.py`

この 2 つが、日本語で書いたコードを **自動で普通の Python コードに変換して実行**してくれます。

👉 **Python 本体をビルドしたり、特別な設定をする必要はありません。**  
安心して読み進めてくださいね。

---

## 📥 1. 必要なファイルをダウンロードしましょう

GitHub ページ：  
`https://github.com/rabbit-hand/Python-Japanese（）` [(github.com in Bing)](https://www.bing.com/search?q="https%3A%2F%2Fgithub.com%2Frabbit-hand%2FPython-Japanese%25EF%25BC%2588%25EF%25BC%2589")

ダウンロードするファイルは次の 2 つです。

- `Lib/japanese_keyword.py`  
- `Tools/japanese_preprocessor.py`

この 2 つを、**同じフォルダに入れておくだけで準備完了**です。

---

## 📝 2. 日本語でプログラムを書いてみましょう

まずは簡単な例から始めましょう。  
`hello.py` という名前のファイルを作り、次のように書きます。

```python
もし 1 < 2:
    表示("こんにちは")
```

とてもシンプルで、読みやすいですよね。

---

## ▶️ 3. 日本語のまま実行してみましょう

ターミナル（コマンドプロンプト）を開いて、次のように入力します。

```bash
python japanese_preprocessor.py hello.py
```

すると、  
あなたが日本語で書いたコードが内部で英語の Python に変換され、  
そのまま普通の Python として実行されます。

---

## 🔧 4. どうして日本語で動くの？（やさしい説明）

- 「もし → if」「表示 → print」などの変換ルールが  
  **`japanese_keyword.py` にまとめられています。**

- `japanese_preprocessor.py` があなたの日本語コードを読み取り、  
  **英語の Python コードに書き換えてくれます。**

- 最後に、変換されたコードが普通の Python として実行されます。

つまり、  
**日本語で書いても、裏側ではちゃんと Python が動いている**という仕組みです。

## 📚 5. よく使う日本語キーワード（初心者向け）

| 日本語 | Python |
|-------|--------|
| もし | if |
| あるいは | elif |
| それ以外 | else |
| 繰り返し | for |
| 関数 | def |
| 戻る | return |
| 表示 | print |
| 読み込み | import |

（GitHub の一覧を初心者向けにやさしくまとめています ）

## 🧪 6. 少し実用的な例も見てみましょう

`calc.py` を作って、次のように書きます。

```python
関数 足し算(a, b):
    戻る a + b

表示( 足し算(5, 3) )
```

実行方法は同じです。

```bash
python japanese_preprocessor.py calc.py
```

---

## 🚫 7. 注意しておきたいこと

- 日本語キーワードは **コードの外（文字列やコメント）では変換されません。**  
- Python 本体をビルドする必要はありません。  
- 標準ライブラリの関数名は日本語化されていません。  
- 変換後のコードは普通の Python として動きます。

（GitHub の注意点を初心者向けにやさしく要約しています ）
