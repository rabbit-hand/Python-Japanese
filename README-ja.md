# 🐣 日本語Python（Python‑Japanese）  
## はじめての方のためのインストール＆使い方ガイド  
※ このガイドは、初心者の方にもわかりやすいように丁寧に書かれています。

---

## 🎯 はじめに  
この日本語Pythonは、  
**「日本語でPythonを書けるようにするための拡張」**です。

GitHub には多くのファイルが含まれていますが、  
日本語でPythonを動かすために必要なのは、次の **2つのファイルだけ** です。

- `japanese_keyword.py`  
- `japanese_preprocessor.py`

この2つが、日本語で書いたコードを **自動で通常のPythonコードに変換して実行**してくれます。

👉 **Python本体をビルドする必要はありません。**  
初心者の方でも安心して使い始められます。

---

## 📥 1. 必要なファイルをダウンロードする

GitHub リポジトリ：  
`https://github.com/rabbit-hand/Python-Japanese`

以下の2つのファイルをダウンロードし、同じフォルダに置いてください。

- `Lib/japanese_keyword.py`  
- `Tools/japanese_preprocessor.py`

これだけで準備は完了です。

---

## 📝 2. 日本語でプログラムを書いてみましょう

まずは簡単な例から始めてみましょう。  
`hello.py` という名前のファイルを作り、次のように書きます。

```python
もし 1 < 2:
    表示("こんにちは")
```

とても読みやすく、自然な日本語で書けます。

---

## ▶️ 3. 日本語のまま実行してみましょう

ターミナル（コマンドプロンプト）を開き、次のように入力します。

```bash
python japanese_preprocessor.py hello.py
```

すると、  
あなたが日本語で書いたコードが内部で英語のPythonに変換され、  
そのまま通常のPythonとして実行されます。

---

## 🔧 4. 日本語で動く仕組み（やさしい説明）

- 「もし → if」「表示 → print」などの変換ルールが  
  **`japanese_keyword.py` にまとめられています。**

- `japanese_preprocessor.py` が日本語コードを読み取り、  
  **英語のPythonコードに書き換えます。**

- 最後に、変換されたコードが普通のPythonとして実行されます。

つまり、  
**日本語で書いても、裏側ではちゃんとPythonが動いている**という仕組みです。

---

## 📚 5. よく使う日本語キーワード一覧

| 日本語 | Python |
|-------|--------|
| もし | if |
| あるいは | elif |
| それ以外 | else |
| 繰り返し | for |
| 関数 | def |
| 戻る | return |
| 表示 | print |
| 読み込み | import |

初心者の方でも覚えやすいように、よく使うものだけをまとめています。

---

## 🧪 6. 少し実用的な例

`calc.py` を作って、次のように書きます。

```python
関数 足し算(a, b):
    戻る a + b

表示( 足し算(5, 3) )
```

実行方法は同じです。

```bash
python japanese_preprocessor.py calc.py
```

---

## 🚫 7. 注意点

- 日本語キーワードは **文字列やコメントの中では変換されません。**  
- Python本体をビルドする必要はありません。  
- 標準ライブラリの関数名は日本語化されていません。  
- 変換後のコードは通常のPythonとして動きます。
